# Kerala Government Calendar 2027 · ഗവൺമെന്റ് ഓഫ് കേരള

A futuristic, highly responsive web application to view the official Government of Kerala 2027 Calendar.

## ✨ Features
- **Kerala Aesthetic & Modern Design**: Authentic Kerala motifs, state emblem, temple gold accents, and deep navy hues inspired by `kerala.gov.in`.
- **Smooth Page Transitions**: Realistic page slide and shimmer lighting animations between months.
- **Full View & Scroll**: Complete, un-cropped view of each month with zoom in/out, fit-to-screen, and smooth vertical scrolling.
- **Interactive Navigation**: Bottom thumbnail ribbon, next/prev controls, direct page number jump, and keyboard shortcuts (`←`, `→`, `+`, `-`, `F`).
- **High Performance**: Powered by PDF.js client-side rendering with zero server load.

## 🚀 Deployment
Deployable with one click on **Vercel** or **GitHub Pages**.
